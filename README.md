# NoteNest

NoteNest is a storefront for digital study notes: visitors can browse and search the notes catalogue, filter by subject and add notes to a basket.

## Technology

The site is one static HTML page (`public/index.html`) with inline CSS and JavaScript. It has no build step or dependencies and is hosted on Netlify.

## Running locally

Open `public/index.html` in a browser, or run `netlify dev` from the project root.
